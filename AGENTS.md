# AGENTS.md

## Project Overview

- **Project**: code examples — anonymized excerpts from production projects
- **Package manager**: `pnpm` only. Never use `npm` or `npx` (use `pnpm` / `pnpm exec` / `pnpm dlx`).

## Local Development

```bash
pnpm install
pnpm storybook        # Storybook dev server on http://localhost:6006
pnpm build-storybook  # static build into storybook-static/
```
